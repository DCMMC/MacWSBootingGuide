Historical event failure and its resolution
-------------------------------------------

`--timer=0` prevents the benchmark from explicitly creating
EXT_disjoint_timer_query_webgl2 queries, but normal ANGLE frame/sync work still
calls `-[MTLDevice newEvent]`. The iOS AGX user client rejects every private
event-create call:

  #### AGXIOC Method sel=0x18->0x18 inCnt=0 inSC=0 outSC=0 -> 0xe00002c2

This was the pre-fix state. RE of the actual macOS 13.4 IOGPU binary and a
runtime byte dump of iOS 16.3 IOGPU subsequently proved that the otherwise
matching initializer uses selector 0x18 on macOS and 0x14 on iOS. The strict
translation now returns a real `_IOGPUMetalMTLEvent`; the fallback does not
fire. An explicit-timer VS Code control completed 64/64 queries with none
pending and a 0.377-ms GPU-time median. See
`private-metal-event-selector-20260729.txt` for the disassembly, byte dump,
exit-0 native/chroot witnesses, benchmark values, and bounded-test limitation.
