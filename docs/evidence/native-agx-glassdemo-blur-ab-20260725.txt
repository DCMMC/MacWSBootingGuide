## Quantitative blur result (runtime-confirmed)

All values below were calculated from the frozen raw BGRA frame using
grayscale `(R + G + B) / 3`.  The sharp controls use rows 1100..1135; the
effect samples use rows 1160..1199, above the HUD label.  The x ranges contain
integer numbers of source cycles.

    high4pt.sharp:  period=16px fundamental=163.386 mean_abs_dx=31.438 min=0.00 max=255.00
    high4pt.effect: period=16px fundamental=0.207   mean_abs_dx=0.035  min=173.00 max=191.00

    mid16pt.sharp:  period=64px fundamental=162.403 mean_abs_dx=7.485 min=0.00 max=255.00
    mid16pt.effect: period=64px fundamental=0.287   mean_abs_dx=0.033 min=173.00 max=185.00

    low48pt.sharp:  period=192px fundamental=162.345 mean_abs_dx=1.997 min=0.00 max=255.00
    low48pt.effect: period=192px fundamental=18.414  mean_abs_dx=0.342 min=157.00 max=201.00

Thus the 4-point input frequency falls by about 57.9 dB, while the 48-point
input still modulates the material by a measurable amount.  The first
black-to-white edge in the 48-point section has:

    black plateau = 160.660
    white plateau = 197.396
    10% crossing   = x 1571.00
    90% crossing   = x 1625.58
    10–90 width    = 54.58 physical pixels
    sharp control  = 1 physical pixel

This combination rules out both unfiltered passthrough and a flat opaque tint:
the low-frequency backdrop still influences the output, its hard edge spreads
over 54.58 pixels, and progressively higher frequencies are suppressed.

## Stability boundary

The automated successful run stopped WindowServer/VNC/GlassDemo immediately
after freezing the framebuffer.  No crash report newer than its start marker
was created; SpringBoard and backboardd were restored, with load average 1.59
at the final check.

This does not close long-run stability.  A preceding attempt ran too long and
created `JetsamEvent-2026-07-25-122331.ips` (SHA-256
`1083826b36c1a4353d1efd9641ae8c1d1183fdceaf73cc5ad68c88b79bd32138`).
It names WindowServer as `largestProcess`, records a 16,384-byte page size, and
lists WindowServer PID 9056 at 743,169 resident pages with reason
`vm-compressor-space-shortage`.  The same attempt produced
`WindowServer-2026-07-25-122215.ips` (SHA-256
`02c2647c25deac4a12a1abed83d5d6dd1680022f09ea9855c1b39b28d32e7c6d`).
